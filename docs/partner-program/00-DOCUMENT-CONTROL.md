# Cortex Partner Program — Document Control

**Document Set:** Cortex Partner Program  
**Owner:** The Cortex Systems  
**Master Version:** 1.0  
**Status:** Approved source-document framework

## Purpose

This folder is the authoritative source-document set for the Cortex Partner Program.

The production platform must implement these documents faithfully. The platform, AI agents, developers, and contractors must not invent substantive business, legal, pricing, Partner-policy, or customer-facing terms that are not contained in an approved source document.

## Source-of-Truth Rule

Approved Cortex documents are the source of truth.

If the application differs from an approved document, the discrepancy must be identified and reviewed before changing either the document or the implementation.

## Versioning

Formal documents must have an explicit version.

A historical version must never be silently overwritten. When a document changes materially, create a new version and preserve the previous version.

## Implementation Rule

AI/development agents may adapt presentation and technical implementation, but must not materially change the meaning of an approved document.

If information required for implementation is missing, STOP and request clarification rather than inventing it.
