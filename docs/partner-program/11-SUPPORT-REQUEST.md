# Cortex Partner Program — Support Request

**Version:** 1.0  
**Route:** `/support`  
**Audience:** Approved Partners

## Purpose

Allows Partners to request technical help from Cortex during or after a project.

## Fields

Collect:

- Project, where applicable
- Issue type
- Description
- Screenshot or supporting file, where useful
- Additional information

## Suggested Issue Types

- BUG
- TECHNICAL_ISSUE
- QUESTION
- PROJECT_SUPPORT
- OTHER

The final values should follow the existing production implementation where applicable.

## Project Relationship

A support request may be linked to a specific project.

If the issue is not related to a specific project, project selection may remain optional.

## Attachments

Screenshots and supporting files may be uploaded through the platform's approved file-storage mechanism.

Do not require sensitive credentials or passwords as attachments.

## Workflow

SUBMITTED
↓
REVIEW
↓
IN_PROGRESS
↓
RESOLVED

The exact statuses should follow the existing production support implementation.
